# MathSolver App Store screenshots — 13-inch iPad

Five AI-enhanced marketing screenshots exported as RGB PNG files at 2064 × 2752 pixels for the 13-inch iPad portrait screenshot slot.

## Art direction

- V2.5 editorial off-white/pale-lavender background with a faint mathematical grid
- Deep navy centered headlines with a short electric-blue accent rule
- Wider 3:4 layouts with intentional negative space and restrained mathematical notation
- Straight-on app screens with the same complete product-panel breakouts as the approved iPhone set
- Exact benefit order, equations, app labels, tutorial artwork, and handwritten-work feedback preserved
- No generated video: screenshot 4 uses the approved static quadratic tutorial thumbnail inside the Video lesson UI

## Source and simulator note

The installed simulator set contained an iPhone 17 Pro but no iPad device. To honor the no-download/no-new-simulator constraint, these layouts were recomposed from the approved iPhone marketing captures. They have valid 13-inch iPad dimensions, but they are not native iPad simulator captures.

## Final set

1. **Solve any math problem** — centered Home screen with the complete “Scan a problem” breakout.
2. **Learn with AI-checked steps** — solution screen with the complete “Independent AI review” breakout.
3. **Check handwritten work** — camera view with blue student handwriting and distinct mint/coral app feedback.
4. **Create your AI video tutorial** — contained quadratic tutorial thumbnail and visible lesson benefits.
5. **Practice until it sticks** — quiz screen with the complete corrective-feedback breakout.

Every generation prompt prohibited invented UI, altered formulas, changed visible labels, extra claims, badges, watermarks, and dramatic perspective.
